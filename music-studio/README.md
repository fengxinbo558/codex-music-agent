# Codex Music Agent Studio

这是建立在官方 [`openai/codex`](https://github.com/openai/codex) 仓库中的桌面 AI 音乐产品原型。Codex 是制作人 Agent：理解用户想法、读取当前工程状态并输出结构化制作方案；音乐模型是独立 Provider，负责真正生成音频。

## 当前已经打通

- 项目首页、创作台、素材库、模型中心四个完整工作区。
- 新建作品、最近项目、素材筛选/导入、模型状态与安装计划。
- 文字或系统语音输入音乐想法。
- 通过官方 `@openai/codex-sdk` 调用本机 Codex，输出受 JSON Schema 约束的 MusicBrief。
- Codex 不可用时自动启用内置规划器，产品仍可体验。
- 整首生成、局部重绘、续写延展和重新编曲四种制作模式。
- 多轨时间线、片段选择、歌词编辑、混音控制、任务队列与制作范围镜头。
- 自动检测并优先调用本机 `ACE-Step 1.5`，生成带歌词演唱的真实音乐。
- 默认只要一句话即可生成；需要时再展开选择 30/60/90 秒、女声/男声/纯音乐、自动/当前歌词、创意幅度和 1/2 个版本。
- ACE-Step 未启动时才使用原型合成器，并明确标注“链路试听”，不会冒充真实 AI 音乐。
- 桌面应用会自动启动适配 Apple Silicon 的 MLX 模型服务。
- 一次生成两个版本时会取得两个独立音频；每个版本分别保存音频、歌词、轨道、参数和 seed，切换版本会真正切换试听内容。
- 生成完成后可以直接“再生成一版”“只改副歌”“做一首新歌”或“导出作品”。新版本留在当前作品里，新歌则建立独立作品。
- 失败时保留原想法和全部设置，可以一键重试。
- 每次生成创建不可覆盖的新版本，支持版本 A/B 对比与当前版本 WAV 导出。
- 界面状态本地保存，支持窄窗口与桌面宽屏。

## 生成策略

默认路由是“ACE-Step 本地真实生成 → Prototype Synth 兜底”。前者在本机运行，不按次收费；后者只用于模型尚未启动时验证交互链路。阿里 FunMusic 等云端模型仍保留为后续可选 Provider，不写死在 UI 或 Agent 中。

当前实机验证中，ACE-Step 在 Apple Silicon 上一次生成两首 30 秒歌曲约需 55 秒。时长、设备和创意设置不同，实际等待时间会变化；界面会持续显示生成阶段和预计耗时。

## 本地运行

在仓库根目录执行：

```bash
corepack pnpm install
corepack pnpm --filter @codex-music/studio desktop
```

桌面模式会自动查找 `../local-models/ACE-Step-1.5` 并启动 8001 端口。第一次真实生成会下载官方模型权重并建立缓存，耗时取决于网络；之后不需要重复下载。

只看浏览器界面：

```bash
corepack pnpm --filter @codex-music/studio dev
```

浏览器模式不直接调用 Codex，会使用内置规划器；如果本机 8001 端口的 ACE-Step 正在运行，浏览器同样会生成真实音乐。桌面模式优先使用 `CODEX_PATH` 指定的二进制；macOS 上也会自动查找 ChatGPT 应用自带的 Codex。

构建完成后，也可以直接双击 `music-studio/index.html`。它会自动打开 `dist/index.html` 中的完整成品，不会再误加载开发源码。

## 安全边界

Electron 页面关闭 Node.js 能力并启用上下文隔离和沙箱。前端只能调用 `planMusic`，不能执行任意命令或读取密钥。Codex 规划线程在空的工程目录中以只读沙箱、禁止联网、永不请求执行审批的方式运行。
