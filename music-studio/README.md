# 音乐创作台

面向第一次写歌的人设计的本机 AI 音乐工作台。产品沿用当前仓库的 Agent 运行能力，但用户看到的是独立的“音乐创作台”品牌；制作人 Agent 负责理解、推荐、调度和检查，ACE-Step 等音乐模型负责真正生成音频。

## 当前已打通

- 从一句模糊想法开始：创意助推器会补充情绪、场景、唱给谁、故事转折和副歌金句，所有内容只追加、不覆盖用户原话。
- 逐步确认工作流：创作方向 → 歌词与唱法 → 30 秒核心小样 → 完整歌曲 → 终检交付；未确认时不会越级调用音乐模型。
- 三套创作方向：推荐、稳妥和大胆方案都展示曲风、速度、调性、情绪、声线、配器与结构，用户可直接修改后再确认。
- 五种歌词写法：口语叙事、现代诗意象、对话体、散文感和短句钩子。系统按创意排序并解释适用场景、风险和参考句。
- 歌词重新起草：按选择的写法另起一稿，上一稿可撤回；每句仍需人工确认。
- 专业歌词质检：确认前检查核心主题、人物关系、关键事实、段落推进、贯穿意象、副歌因果、可演唱性和套话风险；事实丢失或主题跑偏时不会进入生成。
- 逐句演唱设计：怒音、哭腔、呐喊、克制、气声、沙哑、颤音、转音、滑音、拖腔、停顿、念白和清楚咬字等都可逐句选择。
- 本机真实生成：自动调用 ACE-Step 生成带演唱的 WAV；模型未启动时明确提示，不用假音频冒充成品。
- 多候选严选：核心小样内部一次生成 4 个候选，逐个做真实分轨与唱词检查；只要有合格版本就交付最优候选，失败候选仍可试听但不能采用。
- 整首分段严选：长歌词按均衡段落拆成约 30 秒的演唱单元，每段最多自动尝试 8 个候选；只有逐段唱词与咬字都通过后才在本机柔和衔接成整首。
- 声音优化：保留模型原声，同时生成降低尖锐感、保护人声咬字的优化版本。
- 跟唱歌词：Demucs 先提取真实人声，MLX Whisper 再用无提示和歌词引导两次识别；长歌会分窗对齐并合并绝对时间，生成可点击的逐句歌词，没有真实对齐数据的版本不能交付。
- 真实分轨：完整歌曲可用 Demucs 分离为人声、鼓、贝斯和其他乐器，只有时长与重构质量检查通过后才显示四条真实波形。
- 逐句音高微调：选择一句歌词并升降 1–3 个半音；系统先检测真实人声基频，再调整人声、重新混回乐器并建立非破坏新版本。
- A/B 对比：A、B 可独立试听、暂停和从头播放；“试听”和“正式采用”分开，唱词未通过的版本不会误用。
- 本机作品库：音频、歌词、参数、版本、确认记录和任务状态保存在本机；支持单版本删除和清空生成结果，清空时保留创意、方向与歌词草稿。
- 窄窗口与桌面宽屏均可使用，主工作区和制作人面板各自保持可滚动、可到达。

## 真实生成链路

```text
用户想法
  → 制作人 Agent 给出方向与歌词建议
  → 用户逐步确认
  → ACE-Step 生成真实 WAV
  → 长歌逐段生成、逐段严选并衔接
  → 声音优化与本机保存
  → Demucs 真实分轨
  → MLX Whisper 双通道唱词识别与逐句对齐
  → 多候选质量门筛选
  → 可选的逐句音高编辑与重新混音
```

默认优先使用本机模型，不产生按首 API 费用；计算时间取决于歌曲时长和机器性能。云端音乐模型可以在后续作为可选 Provider 接入，不写死在产品界面里。

## 本地运行

在仓库根目录安装前端依赖：

```bash
corepack pnpm install
```

首次启用真实分轨和逐句音高编辑，在 `music-studio/local-audio-service` 初始化隔离环境：

```bash
uv sync --group dev
```

启动桌面应用：

```bash
corepack pnpm --filter @codex-music/studio desktop
```

桌面模式会自动启动本机 ACE-Step（8001）和本机音频服务（8002）。如果只看浏览器界面，需要分别启动服务和 Vite：

```bash
cd music-studio/local-audio-service
uv run uvicorn audio_service.app:app --host 127.0.0.1 --port 8002
```

```bash
corepack pnpm --filter @codex-music/studio dev
```

浏览器模式使用内置规划器，桌面模式通过仓库内的 Agent SDK 生成结构化制作方案。两种模式都可以连接同一套本机音乐与音频服务。

## 验证

```bash
corepack pnpm --filter @codex-music/studio test
corepack pnpm --filter @codex-music/studio build
cd music-studio/local-audio-service && uv run pytest -q
```

## 安全边界

桌面页面关闭 Node.js 能力并启用上下文隔离和沙箱。前端只能请求结构化音乐规划，不能执行任意命令或读取密钥。本机音频服务只接受受限大小和格式的音频，并把输出限制在自己的数据目录中。
