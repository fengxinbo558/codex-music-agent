# 真实音乐工作流实施计划

目标：落实已批准的真实 Agent 工作流、中文歌词清晰优先、跟唱歌词和功能真实性收口。

## 1. 数据与生成参数

- 在生成偏好中增加 `lyricClarity`，人声默认 `clear`，纯音乐忽略。
- 新增中文清晰演唱定义，统一维护正向提示、负向提示和参数。
- ACE-Step 请求在清晰模式下写入 `vocal_language=zh`、`shift=3.0`、受控 `lm_cfg_scale` 和人声前置约束。
- 给请求映射、默认值和兼容旧本地数据补单元测试。

## 2. 真实工作流状态

- 新建独立工作流模块，定义专业角色、真实事件、步骤状态和完成门。
- Provider 进度事件携带稳定阶段代码和真实任务接受事件，不再只传展示文案。
- App 在规划、提交、生成、保存、母带、歌词时间和就绪时写入工作流事件。
- Agent 面板显示角色产物、当前交接和完成依据，移除纯定时百分比。
- ACE-Step 离线时不再从主按钮生成假歌曲版本。

## 3. 跟唱歌词

- 新建歌词时间服务，把段落标签和空行过滤后，按结构、行长和音频时长生成确定性 `LyricCue[]`。
- `ProjectVersion` 保存歌词时间和来源，刷新后可恢复。
- 新建跟唱歌词组件，显示上一句、当前句和下一句；跟随播放高亮并允许点击跳转。
- 补歌词估时、当前行选择、边界和纯音乐测试。

## 4. 功能真实性收口

- 局部重绘、续写和未带参考源的重新编曲改为锁定状态，并解释真实依赖。
- “只改副歌”在接通 repaint 前锁定。
- 多轨混音、静音、独奏和添加音轨锁定，说明当前结果是单一混合 WAV。
- 保留真实可用的整首生成、参考风格、翻唱/重编、版本、素材库、播放和导出。

## 5. 视觉、验证与实机听测

- 为专业 Agent 步骤、交接、完成证据、跟唱歌词和锁定状态补响应式样式。
- 运行全部前端测试、类型检查和生产构建。
- 在本地创作台检查宽屏和窄屏交互，截图验证。
- 使用固定歌词和可复现参数生成清晰版，检查歌词可辨识度、尖锐度和伴奏遮挡；不把主观听感写成自动质检通过。
