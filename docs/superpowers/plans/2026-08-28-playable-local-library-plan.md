# 真实可播放本机素材库：实施计划

设计依据：`docs/superpowers/specs/2026-08-28-playable-library-reference-cloud-design.md`

## 1. 建立可持久化音频资产模型

- 扩展 `MusicAsset`，加入生成结果类型、真实秒数、MIME、大小、波形、本机 Blob 键和同步状态。
- `ProjectVersion` 增加 `audioAssetId`，Blob URL 只保留为会话期兼容字段。
- 增加资产工厂与格式化函数测试，确保导入和生成结果使用同一模型。

## 2. 建立 IndexedDB 音频仓库

- 新增 `LocalAudioStore`，用独立 object store 保存资产元数据和 Blob。
- 支持保存、读取、列出和删除；数据库不可用时明确报错，不制造已保存状态。
- 使用 `fake-indexeddb` 覆盖刷新后的读取、Blob 内容和同 ID 更新测试。

## 3. 完成真实导入

- `LibraryView` 把 File 交给 App，不再自行创建只有名字的记录。
- 使用真实音频解码取得时长；可以解码时生成波形，失败时阻止入库并显示原因。
- 保存成功后刷新素材状态；默认素材库不再展示不可播放的演示资产。

## 4. 建立统一播放链路

- 新增音频资产解析器：优先从 IndexedDB 取得 Blob，并创建会话期 Object URL。
- App 的唯一 `<audio>` 同时服务创作台、素材库和时间线。
- 素材列表与详情提供真实播放/暂停，选中素材与播放素材状态分离。
- 切换播放源时释放旧临时 URL，浏览器拒绝自动播放时显示明确提示。

## 5. 完成时间线片段试听

- 片段选择按钮与试听按钮拆分，避免嵌套交互和语义冲突。
- 根据工程时间位置与真实音频时长计算试听起止秒数。
- 播放到片段结束处自动暂停；再次点击可以停止。
- 补充键盘和 ARIA 标签，窄屏仍能操作。

## 6. 生成结果自动入库并恢复版本

- ACE-Step / Mock 返回 Blob URL 后读取 Blob，先存入 IndexedDB，再创建版本。
- A/B 结果分别创建生成资产并自动进入“生成结果”筛选。
- 版本保存 `audioAssetId`；版本元数据写入本地存储时去除会失效的 Blob URL。
- 应用启动时读取资产与版本，当前版本可以恢复可播放源。
- 新建歌曲清空当前项目播放和版本，但不删除素材库资产。

## 7. 验证

- 单元测试：资产模型、IndexedDB 保存/读取、音频区间映射、版本序列化。
- 生产构建与 Electron 入口语法检查。
- 实际导入现有 WAV，刷新后读取并试听。
- 实际生成 A/B，确认素材库新增两个不同资产且版本切换可播放。
- 检查无音频素材不会显示可用播放按钮。
- 检查 416px 下素材播放和片段试听控件可见、可聚焦。

第一阶段验收后，进入 `real-reference-generation` 实施计划。
