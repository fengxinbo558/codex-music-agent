# 温暖细腻生成与柔化重制：实施计划

设计依据：`docs/superpowers/specs/2026-08-28-warm-emotional-audio-design.md`

## 前端设计校准

- **对象与单一任务**：面向不懂混音的小白创作者；页面任务是用一句话生成音乐，并在听感刺耳时一键得到更温暖的版本。
- **现有视觉语言**：沿用工作室深紫黑 `#100d13`、面板 `#151119`、暖金 `#dba35d`、柔紫 `#a98ad1`、薄荷绿 `#72c9ae`；不引入一套新的营销页面风格。
- **字体角色**：中文正文继续使用 Avenir Next / PingFang SC，状态与制作数据继续使用 DM Mono 风格的等宽字；不增加网络字体依赖。
- **布局**：质感选择嵌入现有“这次怎么做”折叠设置；柔化动作只出现在当前版本上下文和生成完成后的下一步区域，不另建复杂页面。
- **标志性元素**：三个质感选项各带一个小型“音色指纹”曲线，温暖档低端更饱满、自然档平衡、明亮档高端抬起。它既帮助小白理解差异，也延续时间线和波形的音乐产品语言。
- **自我审查**：不使用常见的大渐变卡片、发光玻璃或无意义动效。唯一的视觉强调留给音色指纹和正在处理时的柔和扫光；支持键盘焦点和减少动态设置。

## 1. 建立声音质感模型

- 新增 `ToneProfile` 与三个质感的集中定义，包括标签、说明、正向描述、负面描述和音频参数。
- 扩展 `GenerationPreferences` 与默认值，旧设置缺少字段时自动补成 `warm`。
- 扩展版本与素材元数据，记录父版本、原声来源、处理质感、处理时间、素材可见性和音频角色。
- 先补数据定义、设置摘要、旧数据兼容与素材筛选测试。

## 2. 改善 ACE-Step 生成表达

- 将质感正向描述追加到现有音乐提示。
- 使用 ACE-Step 官方已支持的 `lm_negative_prompt` 抑制刺耳、金属感、过度压缩、机械咬字和僵硬节奏。
- 纯音乐模式移除演唱描述；自由生成、参考风格、翻唱模式保持原任务字段和参考强度。
- 扩展提供器测试，验证三档质感和纯音乐分支。

## 3. 实现真实本机音频优化

- 新增独立 `audioMastering` 服务：解码、离线均衡、轻压缩、峰值保护、PCM WAV 编码。
- 将具体参数保存在纯配置中；温暖档削高频最明显，自然档更轻，明亮档只控制刺耳区域。
- 编码器支持单声道与立体声，保留采样率和时长；输出留出约 1 dB 峰值余量。
- 单元测试覆盖参数边界、合法 WAV 头、声道交织、峰值归一和有限样本；真实浏览器覆盖完整离线处理。

## 4. 接入新歌保存链路

- 模型返回后先保存隐藏的原声素材，再执行音频优化并保存可见优化素材。
- 每个模型结果只创建一个可见作品版本；`audioAssetId` 指向优化结果，`mastering.sourceAssetId` 指向原声。
- 优化失败时让版本改用原声并展示“柔化未完成”，不能丢失已经生成的音乐。
- 处理多个结果时保持顺序；错误时清理无引用半成品。

## 5. 完成小白质感设置

- 在现有生成设置中加入“声音质感”三选一与音色指纹。
- 默认选择“温暖细腻”，折叠摘要显示当前质感。
- 文案只说用户可感知的听感，不出现 EQ、Q 值、阈值等专业参数。
- 补充键盘、ARIA、禁用状态和现有窄屏布局适配。

## 6. 完成旧版本柔化重制

- 给拥有真实音频且未柔化的当前版本提供“柔化重制”。
- 从 IndexedDB 读取来源 Blob，按温暖档处理后新建带父版本关系的独立版本。
- 成功后自动切换并播放；失败不产生空版本；处理期间禁止重复点击。
- 已柔化、无真实音频和正在处理的版本显示准确状态。

## 7. 完成原声与优化对比及导出

- 已优化版本提供“原声 / 柔化”切换；明亮档显示“原声 / 优化”。
- 播放与波形随素材真实切换，刷新后默认回到优化音频。
- 导出严格读取当前试听状态对应的素材，而不是固定导出版本主素材。
- 普通素材库隐藏内部原声来源，但版本对比仍可读取它。

## 8. 错误恢复与持久化

- 区分模型失败、优化失败、解码失败和保存失败，给出下一步动作。
- 新歌优化失败保留原声并提供重试；旧歌优化失败保持当前版本。
- 页面刷新后恢复质感、版本关系、主音频和原声切换能力。
- 保持现有旧版本、导入素材和参考音频不受影响。

## 9. 验证与听感校准

- 运行全部单元测试、类型检查和生产构建。
- 在真实 ACE-Step 链路生成默认温暖新歌，检查生成、柔化、保存、播放、刷新、原声切换与导出。
- 对现有版本执行柔化重制，确认生成独立版本且原歌仍可播放。
- 使用频谱/峰值检查确认没有削波，温暖档的高频能量低于同一原声。
- 真实 A/B 试听，必要时只微调集中配置中的轻量参数，避免为某一首歌过拟合。
- 在正常桌面宽度和项目现有最小宽度检查布局、焦点与处理状态。
