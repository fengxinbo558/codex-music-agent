# Codex Music Agent 完整产品原型设计

日期：2026-08-27  
状态：Go 模式已授权，沿用已批准的产品方向  
范围：桌面端高保真产品 Demo；2026-08-28 经用户授权扩展为真实 ACE-Step 本地生成

## 1. 目标

把现有的单屏“编曲台 + Agent”验证原型扩展为一套可完整体验的 AI 音乐桌面产品。用户应该能够从项目首页进入创作、管理音乐素材和模型连接，在创作台完成想法输入、范围选择、生成、歌词修改、版本比较和导出。所有高风险或未接入能力必须如实显示状态，不用假按钮伪装为已实现。

本轮继续以官方 Codex 为 Agent 底座，音乐模型保持可插拔。Codex 负责理解、规划和调用；音乐 Provider 负责声音生成；桌面 UI 负责项目状态和用户控制。

## 2. 产品信息架构

应用包含四个一级页面：

1. **项目**：继续最近创作、新建项目、模板入口、最近生成任务和系统准备状态。
2. **创作台**：播放控制、多轨时间线、歌词/混音/版本底部工作区和固定 Agent 面板。
3. **声音与素材**：用户声音、参考音频、节奏、乐器片段和收藏素材的管理视图。
4. **模型中心**：Codex Agent、ACE-Step、本地分轨、语音输入和云端 Provider 的能力与连接状态。

设置、帮助、导出、版本比较和新建项目使用弹窗或抽屉，不增加第五个空泛的一级页面。

## 3. 核心用户流程

### 3.1 新建作品

项目首页点击“新建作品”，用户输入标题、创作想法，并选择空白、中文流行、氛围器乐三个起点之一。创建后进入创作台，输入内容自动带入 Agent，不要求用户重复描述。

### 3.2 生成与修改

创作台提供四种明确操作：

- 生成整首：建立完整新版本。
- 改选中片段：只在已选择片段和 Provider 能力允许时启用。
- 延长作品：从当前结尾继续。
- 重新编曲：锁定歌词和人声方向，重做伴奏。

Agent 右栏持续展示操作范围、保留项、修改项、Provider、预计时间与费用。生成不会覆盖现有版本。

### 3.3 版本比较与导出

用户从左侧版本列表或底部“版本”页进入 A/B 比较。比较界面展示两个版本的来源、速度、调性、操作摘要和波形，并提供切换试听。导出界面支持 MP3、WAV 和分轨 ZIP；原型中生成本地演示文件，未接入的格式会清楚标为“接入真实音频后可用”。

### 3.4 模型连接

模型中心把“Agent 大脑”和“音乐/音频工具”分开：

- Codex Agent：已连接时显示当前会话能力。
- ACE-Step：显示未安装、准备中、可用或错误状态，以及完整歌曲/续写/局部重绘能力。
- Demucs：显示分轨能力和本地状态。
- FunMusic：显示云端可选与权限检测状态，不收集或暴露密钥。

## 4. 创作台布局

```text
┌────────左导航────────┬────────────顶部播放与工程控制────────────┬────AI 制作人────┐
│ 项目 / 创作台        │ 当前作品 / 播放 / BPM / 调性 / 导出      │ 当前范围          │
│ 素材 / 模型中心      ├─────────────────────────────────────────┤ 理解与制作计划    │
│                      │ 时间线工具 / 段落尺 / 多轨波形            │ 模型 / 成本 / 进度 │
│ 当前项目与版本       │                                         │                  │
│                      ├─────────────────────────────────────────┤ 对话与输入        │
│ 系统状态             │ 歌词 / 混音 / 版本 / 任务记录             │                  │
└──────────────────────┴─────────────────────────────────────────┴──────────────────┘
```

中央工作区保留专业密度，但首要任务永远是“看懂歌曲结构”和“明确 Agent 会改哪里”，不追求复刻完整 DAW。

## 5. 视觉系统

### 5.1 色彩

- `Smoke #100D13`：主背景，接近隔音室暗面。
- `Plum #1C1720`：面板与控制台表面。
- `Tungsten #DBA35D`：播放头、主操作和 Agent 操作线。
- `Wave Violet #A98AD1`：人声与 Agent 推理状态。
- `Meter Mint #72C9AE`：完成、可用和音量计。
- `Fault Rose #E07D8D`：失败与不可用。

### 5.2 字体与密度

中文正文使用系统黑体栈，标题使用较紧的中等字重；时间码、参数和模型标识使用等宽字体。界面不依赖联网字体。标题层级只分三层，卡片不使用大面积圆角和浮夸渐变。

### 5.3 记忆点

唯一高识别元素是“Agent 操作线”：时间线选择或当前生成模式通过一条细金线连接到右侧操作镜头，右侧明确列出保留、修改和输出版本。它不是装饰，而是用户控制 AI 边界的可视化。

## 6. 组件与状态

### 6.1 全局状态

- 当前一级页面。
- 当前项目、版本和播放状态。
- Provider 与系统准备状态。
- 弹窗、通知和最近任务。
- 用户偏好和首次引导状态。

页面级状态保存在浏览器本地存储，刷新后恢复当前项目和偏好；音频大文件不放入本地存储。

### 6.2 通用组件

- 一级导航与项目切换。
- 全局状态条与通知中心。
- 原生语义弹窗，支持 Escape、初始焦点和关闭后焦点恢复。
- 状态徽标、空状态、错误状态和加载骨架。
- Provider 能力表和费用提示。

### 6.3 创作组件

- 时间线工具栏：生成方式、吸附、缩放、添加轨道。
- 多轨与片段：选择、静音、独奏、音量和锁定。
- 歌词编辑器：可编辑行、保存歌词版本、Agent 改写入口。
- 混音器：轨道音量、声像和效果量的原型控制。
- 版本比较：A/B、来源、变化摘要和恢复入口。
- 导出：格式、质量、包含内容和导出结果。

## 7. 错误、空状态与诚实边界

- 直接打开源码入口时，文档和运行入口都指向稳定本地预览或桌面脚本。
- ACE-Step 未安装时不显示为“在线”，而显示“待安装”；原型合成器标记为“链路演示”。
- 云端模型未配置时禁用生成并说明需要的条件。
- 没有素材时用明确的导入入口，不制造虚假素材数量。
- 导出未接真实音频时，只允许导出当前演示 WAV；MP3 和分轨包解释其依赖条件。
- Agent 失败时保留用户输入并提供本地规划器，不创建空版本。

## 8. 无障碍与键盘

- 所有控件使用原生按钮、输入、选择器和滑块。
- 一级导航、页签和弹窗提供正确语义与状态。
- 弹窗支持 Escape 关闭、焦点圈定和焦点恢复。
- 图标按钮都有可访问名称；状态变化使用 `aria-live`。
- 文本与交互颜色达到足够对比；选中状态不只依赖颜色。
- `prefers-reduced-motion` 下关闭非必要动画。
- 关键快捷键：空格播放、Command/Ctrl + Enter 开始制作、Command/Ctrl + E 导出。

## 9. 原型完成标准

- 正确地址能在应用内浏览器打开，并在本轮结束后保留。
- 四个一级页面都具有真实内容和可用导航。
- 新建项目、选择生成模式、片段选择、歌词编辑、生成、版本新增、A/B 比较和导出流程可体验。
- 模型中心明确呈现 Codex、ACE-Step、Demucs、语音输入和云端模型状态。
- 页面刷新后保留关键 UI 状态。
- 桌面构建、单元测试和浏览器端到端测试通过。
- UI 不声称已经具备尚未接入的高质量音乐模型能力。

## 10. 自检

- 无 `TODO`、`TBD` 或待用户决定项。
- 信息架构、核心流程和错误边界与既定产品设计一致。
- 范围聚焦在完整高保真原型，不把真实模型安装、支付或发行系统混入本轮。
- Codex Agent 与音乐 Provider 仍然保持独立，不修改 Codex 核心协议。

## 11. 真实生成扩展（2026-08-28）

### 11.1 面向小白的成功标准

用户不需要理解模型、BPM、调性或音轨。进入创作台后，首屏先看到“一句话，做一首歌”，输入故事、情绪和声音方向即可开始；专业时间线仍保留在下方，供生成后继续修改。

### 11.2 模型架构

- 桌面应用启动独立的 ACE-Step 1.5 REST 服务，不把模型代码塞入渲染进程。
- Apple Silicon 使用 MPS + MLX；当前机器使用官方推荐范围内的 1.7B LM 和 Turbo DiT。
- Provider 顺序固定为“ACE-Step 本地真实生成 → Prototype Synth 离线兜底”。
- 健康状态分为检查中、首次准备、可用、未启动；UI、版本和任务记录都显示真实 Provider，不用演示结果冒充模型结果。
- 第一次启动先开放本地健康接口，再在后台下载并加载模型；生成按钮在准备期间禁用，避免重复初始化。

### 11.3 数据流

一句话输入先由 Codex 或内置规划器整理为 MusicBrief，再由 ACE-Step Provider 提交异步任务。前端轮询真实阶段与进度，完成后读取本地 WAV，创建新版本并解锁试听和导出。失败时保留输入、旧版本和任务记录，用户可以直接重试。

### 11.4 验收

- M1 Pro / 32GB 机器能自动启动本地服务并完成真实音乐生成。
- 浏览器和桌面界面能识别模型首次准备、可用和离线状态。
- 窄窗口下生成输入与主按钮位于时间线之前并在首屏可见。
- 真实生成结果可播放、可导出、可在版本和任务中识别来源。
- TypeScript 构建、Provider 单元测试和实际 API 生成同时通过。
