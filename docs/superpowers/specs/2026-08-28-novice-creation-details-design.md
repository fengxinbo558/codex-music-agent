# Codex Music Agent：小白创作全流程细化设计

日期：2026-08-28  
状态：已确认，按推荐的“渐进式小白创作台”实施

## 1. 目标

在不破坏“一句话，做一首歌”主入口的前提下，让用户能够连续创作多首歌、生成同一首歌的多个真实版本，并在生成前控制少量真正有效的参数，在生成后立即知道下一步能做什么。

成功标准：

- 第一次使用的人不用理解模型、采样或推理参数。
- 默认路径仍然只需要输入一句话并点击一次按钮。
- 细节设置映射到 ACE-Step 的真实请求，不出现装饰性控件。
- “新作品”和“当前作品的新版本”在文案和结果上明确区分。
- 每个生成版本保留自己的音频、参数、提示词和来源；切换版本即可切换试听。
- 手机窄窗口和桌面宽屏都能在时间线之前完成创作。

## 2. 方案选择

采用渐进式小白创作台，不采用强制三步向导，也不采用常驻专业参数面板。

- 默认层只显示一句话输入、当前创作配方摘要和主按钮。
- “细节设置”按需展开；设置使用生活化语言，不暴露 `temperature`、`top_p`、`batch_size` 等模型术语。
- 生成完成后，原来的说明区切换为“作品已就绪”结果台，提供下一步快捷动作。
- 时间线与歌词、混音、版本、任务仍保留在下方，服务生成后的深入编辑。

## 3. 视觉与布局

## 4. 生成前细节

新增 `GenerationPreferences`，所有选项有明确默认值并写入本地状态：

| 用户控制 | 选项 | 默认 | 真实映射 |
| --- | --- | --- | --- |
| 歌曲长度 | 30 / 60 / 90 秒 | 30 秒 | `audio_duration` |
| 演唱方式 | 女声 / 男声 / 纯音乐 | 女声 | 写入音乐提示；纯音乐时歌词传空字符串 |
| 歌词 | 自动写词 / 使用当前歌词 | 自动写词 | 决定使用 Agent 新歌词或编辑器现有歌词 |
| 创意程度 | 稳定 / 平衡 / 惊喜 | 平衡 | 映射 LM temperature、top-p 和随机种子策略 |
| 生成数量 | 1 个 / 2 个版本 | 1 个 | `batch_size` |

创意程度映射固定为：

- 稳定：`lm_temperature=0.70`、`lm_top_p=0.82`
- 平衡：`lm_temperature=0.85`、`lm_top_p=0.90`
- 惊喜：`lm_temperature=1.00`、`lm_top_p=0.95`

纯音乐模式自动关闭歌词方式控件，但不删除歌词编辑器内容；切回演唱模式后原歌词仍在。

配方条始终显示生效值，并显示粗略耗时：30 秒约 1 分钟，60 秒约 1–2 分钟，90 秒约 2–3 分钟；选择两个版本时提示耗时可能增加。耗时只写“预计”，不能伪装为准确倒计时。

## 5. 真实多版本结果

Provider 从返回单个 `GeneratedAudio` 改为返回 `GeneratedAudio[]`。ACE-Step 完成时读取结果数组中的每个音频文件；离线试听兜底始终只返回一个，并明确告知原因。

每个 `ProjectVersion` 新增：

- `audioUrl`
- `prompt`
- `duration`
- `provider`
- `preferences`
- `seed`
- `createdAt`

当前会话中的 Blob URL 由版本持有。选择一个带音频的版本时：

1. 播放器暂停。
2. 切换 `audioUrl` 和时长。
3. BPM、调性、歌词和配方摘要切换到该版本快照。
4. 时间线展示该版本的生成轨道示意。

只有删除版本或关闭页面时才释放对应 Blob URL，不能在生成下一版时释放上一版。

## 6. 生成后的下一步

生成成功后在 Agent 面板展示四个动作：

- **再来一版**：保留当前提示和设置，重新随机生成。
- **只改副歌**：将生成模式切换为局部/副歌方向，自动填入“保留主歌，只重新设计副歌的旋律、动态与和声”，用户仍可修改后再提交。
- **新建歌曲**：打开新作品对话框，创建后清空音频与当前方案。
- **导出当前版**：直接打开已有导出对话框。

按钮名称与结果提示保持一致。生成两个版本时，结果台显示 A/B 两张紧凑卡片；点击卡片即可播放对应版本，并可进入现有 A/B 对比。

## 7. 失败与恢复

- 失败后保留提示词、细节设置、现有版本和歌词。
- Agent 面板显示明确原因与“重试本次生成”。
- 任务列表中的失败项保留，并记录使用的时长、演唱方式和版本数量。
- ACE-Step 离线时允许用户生成链路试听，但设置区标明仅 16 秒、单版本，避免把兜底结果冒充正式生成。
- Codex 超过三分钟时由内置规划器接手；音乐生成任务本身仍独立进行。

## 8. 新作品与项目状态

“新作品”对话框继续保留一句想法、参考音频、人声小样三个入口，但本轮只有“一句想法”走完整真实链路；另外两个入口继续诚实显示为建立工程后的预留流程。

创建新作品时重置：

- 当前音频与播放状态
- 当前版本列表
- 当前任务选择
- 生成模式
- 提示词与方案

保留用户级偏好：时长、演唱方式、歌词方式、创意程度和版本数量。这样连续做不同歌曲时不需要重复设置。

## 9. 组件边界

- `AgentPanel`：一句话输入、配方摘要、细节设置和完成后动作。
- `GenerationSettings`：纯受控设置组件，不直接调用模型。
- `GenerationResultActions`：只发出再生成、局部修改、新建和导出事件。
- `MusicProvider`：接收 `MusicBrief + GenerationPreferences`，返回一个或多个音频。
- `App`：管理项目状态、版本快照、播放选择和任务生命周期。
- `BottomWorkspace`：展示并切换版本；不拥有音频生命周期。

## 10. 数据流

```text
一句话 + 当前歌词 + 细节设置
          ↓
Codex / 内置规划器生成 MusicBrief
          ↓
根据歌词模式和演唱方式整理最终 Brief
          ↓
ACE-Step 异步任务（时长 / 创意程度 / 版本数）
          ↓
下载一个或两个 WAV Blob
          ↓
创建不可覆盖的版本快照
          ↓
选择试听 / 再来一版 / 只改副歌 / 新建歌曲 / 导出
```

## 11. 验收与测试

单元测试：

- 每个设置到 ACE-Step 请求字段的映射。
- 纯音乐不发送歌词，切换模式不破坏编辑器歌词。
- 中文 R&B 不会被误判为英文。
- 真实任务返回两个结果时创建两个版本。
- 切换版本会切换音频，不会提前释放旧 URL。
- 离线兜底限制为一个版本并显示警告。
- 失败后可用相同输入和设置重试。

产品验收：

- 默认用户仍可只输入一句话完成生成。
- 30、60、90 秒参数真实进入 ACE-Step。
- 至少实际生成一次双版本任务并能分别下载和试听。
- “再来一版”和“新建歌曲”不会混淆或覆盖旧版本。
- 416px 宽度下输入、配方、主按钮和完成后动作位于时间线之前。
- TypeScript、生产构建、全部测试和真实 API 生成通过。

## 12. 非目标

本轮不加入登录、支付、在线发布、版权声明流程、云端同步、永久音频数据库、真正的 Stem 分离或完整 DAW 编辑。上述能力保留在产品架构中，但不能以可点击假功能出现。
